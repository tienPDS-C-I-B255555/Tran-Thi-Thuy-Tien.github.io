TERMINAL > tomtat Message summary

Telegram summary bot

A prototype for catching up on new group messages in a short summary.

  • Node.js
  • Telegram Bot API
  • Gemini API
View case study

Problem

Coming back to a busy group chat means scrolling through many new messages to understand what happened.

Design

I used Node.js to pull Telegram updates, track processed message IDs, and pass collected messages to Gemini when the tomtat command runs.

Outcome

I created the bot and added it to a Telegram group. The prototype accepts the summary command from the terminal.
